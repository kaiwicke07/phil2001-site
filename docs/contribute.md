# Contribute

This site is part of the PHIL 2001 class project. It collects the course tools in one place,
and later it can hold course notes, a glossary, activity writeups and contributor credits.

## Add or change something

- **Spotted a mistake or a broken link?** Click the pencil icon at the top of any page to
  suggest an edit on GitHub. You can also tell Prof. Smead or post in the [class Slack](https://join.slack.com/t/ethicsandevol-t9t5805/shared_invite/zt-4ayaznr0m-ySVsedIYr2STxCtHrn3yvA).
- **Built a new tool?** Once Prof. Smead accepts it, add an entry to the
  [tools list](index.md#tools) the same way the others are written: one line on what it
  does, one thing to try, and links to the app and its code.
- **Writing notes or an activity writeup?** Send it to the class project channel on [Slack](https://join.slack.com/t/ethicsandevol-t9t5805/shared_invite/zt-4ayaznr0m-ySVsedIYr2STxCtHrn3yvA). New pages
  go here once they're accepted.

## Consent

Contributed work only goes up with its author's consent. You can choose to be credited by
name or not. Ask to have your work taken down at any time and it will be removed.
